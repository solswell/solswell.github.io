# SOLSWELL website

Open index.html to view locally. No installation or build is needed.

## Update the existing GitHub Pages website

1. Sign into GitHub and open solswell/solswell.github.io.
2. Upload the contents of assets into the repository's assets folder.
3. Upload index.html, styles.css and script.js into the repository root, replacing the existing versions.
4. Commit the changes to main. Under Actions, wait for pages-build-deployment to finish successfully.
5. Open https://solswell.github.io/ and refresh.

The existing X account is now https://x.com/SolSwellOcean. The previous solmatefun.github.io website redirects visitors to the new website. Preserve its repository and the SOLMATE backup ZIPs.

## Free hosting from a new account

Create a public repository named YOUR-USERNAME.github.io. Upload index.html, styles.css, script.js and assets, keeping their folder structure. Open Settings → Pages → Deploy from a branch → main → / (root) → Save. GitHub will show the published URL.

Keep pre-launch wording until a real launch occurs. Never invent a token address or trading link. Independent community project; not affiliated with or endorsed by the Solana Foundation.
